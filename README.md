- Logistic Regression
- Decision Tree
- Random Forest

## Features
- Medical data analysis
- Disease prediction
- Model evaluation
- Accuracy, Precision, Recall, and F1-Score

## Technologies Used

- Pandas
- Scikit-learn

Diabetes Prediction Dataset
